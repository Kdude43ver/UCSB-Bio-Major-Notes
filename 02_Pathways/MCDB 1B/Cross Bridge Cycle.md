# Cross-Bridge Cycle

**Course:** [[Course Dashboard]] | **Yield:** HIGH ⭐⭐⭐

---

## Pathway Overview

The cross-bridge cycle is the molecular mechanism by which myosin heads repeatedly bind, pull, and release actin filaments to generate muscle contraction. Each cycle consumes one ATP and produces one power stroke of ~5–10 nm displacement.

---

## Step-by-Step Cycle

```
STATE 1: RIGOR STATE
Myosin head (no ATP) tightly bound to actin
        ↓
ATP binds myosin head (ATPase domain)
        ↓
STATE 2: DETACHED
ATP binding → conformational change → myosin releases actin
        ↓
ATP hydrolyzed → ADP + Pᵢ (products remain on myosin)
        ↓
STATE 3: COCKED / PRIMED
Myosin head pivots to 90° (high-energy conformation)
Myosin re-attaches to new actin site further along the filament
        ↓
Pᵢ released → triggers POWER STROKE
        ↓
STATE 4: POWER STROKE
Myosin head pivots from 90° → 45°
Actin filament pulled ~5–10 nm toward M-line
ADP released
        ↓
Returns to STATE 1 (rigor) — ready for next ATP
```

## ATP Roles in the Cycle

| Step | ATP Role |
|------|----------|
| ATP binds (step 1→2) | Detaches myosin from actin |
| ATP hydrolysis (step 2→3) | Cocks (re-energizes) myosin head |
| Pᵢ release (step 3→4) | Triggers power stroke |
| ADP release | Completes power stroke; rigor achieved |

**Key insight:** ATP is needed for both contraction AND relaxation. Without ATP (rigor mortis), myosin stays bound to actin permanently.

## Ca²⁺ Regulation

```
No Ca²⁺ (resting):
Tropomyosin blocks actin-binding sites → cross-bridge cycle CANNOT proceed

↑ Ca²⁺ (contraction signal):
Ca²⁺ binds Troponin C
→ Troponin complex shifts
→ Tropomyosin moves → exposes actin-binding sites
→ Cross-bridge cycle proceeds
```

**Ca²⁺ source in skeletal muscle:**
- Action potential → T-tubule → RYR (ryanodine receptor) on SR → Ca²⁺ released into cytoplasm
- Relaxation: Ca²⁺ pumped back into SR by SERCA (Ca²⁺-ATPase)
