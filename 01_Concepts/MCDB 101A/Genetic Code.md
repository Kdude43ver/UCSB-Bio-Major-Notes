# The Genetic Code

**Topic Area:** Translation
**Lecture:** [[Translation]]
**Exam:** Midterm 2
**Importance:** HIGH YIELD ⭐⭐

---

## One-Line Definition
The genetic code is the set of 64 triplet codons that map to 20 amino acids (plus 3 stop signals), characterized by degeneracy, non-overlap, near-universality, and wobble at the third position.

---

## Properties of the Genetic Code

| Property | Description |
|----------|------------|
| **Triplet** | 3 nucleotides = 1 codon → 64 codons for 20 aa |
| **Degenerate** | Multiple codons → same amino acid (synonymous codons) |
| **Non-overlapping** | Each nucleotide belongs to only one codon |
| **Comma-free** | No punctuation between codons; reading frame set by AUG |
| **Nearly universal** | Same code in virtually all organisms (minor mitochondrial exceptions) |

---

## Special Codons
| Codon | Assignment |
|-------|-----------|
| AUG | Met / START |
| UAA | Stop (Ochre) |
| UAG | Stop (Amber) |
| UGA | Stop (Opal) |

**Only Met (AUG) and Trp (UGG)** are encoded by a single codon — no degeneracy.

---

## Wobble Hypothesis (Crick, 1966)

The **3rd codon position** pairs with the **1st anticodon position** with relaxed (wobble) specificity:

| Anticodon position 1 (5') | Reads codon position 3 |
|--------------------------|----------------------|
| G | C or U |
| C | G only |
| A | U only |
| U | A or G |
| **Inosine (I)** | **C, U, or A** |

This allows ~45 tRNAs to decode all 61 sense codons.

---

## Suppressor tRNAs
Mutations in tRNA anticodons can produce suppressor tRNAs:
- **Ochre suppressor:** tRNA^Tyr with anticodon that reads UAA
- **Amber suppressor:** Most common in lab; inserts Tyr or Gln at UAG
- Important for phage genetics (rII amber mutants)

---

## Common Exam Traps
- Wobble is at the **3rd codon / 1st anticodon** position only
- Inosine (I) is the most permissive wobble base — found in tRNAs, not mRNA
- "Degenerate" does NOT mean random — each codon still maps to exactly one amino acid
