## One-Line Definition
DNA replication is the semiconservative process by which a cell copies its genome, using each parental strand as a template to produce two identical daughter duplexes.

---

## Key Machinery (E. coli)

| Protein | Function |
|---------|---------|
| DnaA | Initiator; opens oriC |
| DnaB (helicase) | Unwinds dsDNA 5'→3' |
| DnaC | Loads DnaB at oriC |
| SSB | Stabilizes ssDNA |
| Primase (DnaG) | Makes RNA primers |
| β-clamp | Processivity factor for Pol III |
| γ-complex | Clamp loader (ATP-dependent) |
| DNA Pol III (αεθ) | Main polymerase; 5'→3' synth + 3'→5' proofread |
| DNA Pol I | Removes RNA primers; fills gaps |
| DNA Ligase | Seals nicks (NAD⁺-dependent in bacteria) |
| Gyrase (Topo II) | Relieves positive supercoils ahead of fork |
| Topo IV | Decatenates daughter chromosomes at termination |

## Core Concepts

### Semiconservative Replication
Proved by **Meselson-Stahl (1958)** using ¹⁵N/¹⁴N CsCl density gradients. Each daughter molecule retains one parental strand.

### Leading vs. Lagging Strand
- **Leading:** Continuous synthesis toward the fork
- **Lagging:** Discontinuous; Okazaki fragments (~1–2 kb in bacteria); each needs its own primer
- Both synthesized 5'→3' by Pol III

### Proofreading
- 3'→5' exonuclease (ε subunit of Pol III) excises misincorporated bases
- Reduces error rate from ~10⁻⁵ to ~10⁻⁷

### oriC Initiation
DnaA binds 9-mer DnaA boxes → melts AT-rich 13-mer repeats → DnaB loaded via DnaC → bidirectional replication begins

---

## Common Exam Traps
- Pol III does NOT remove primers — that's Pol I (5'→3' exonuclease)
- DnaB helicase moves **5'→3' on lagging strand template** (i.e., it moves away from the fork on the lagging strand, which is toward the fork in fork-movement direction)
- Ligase in bacteria uses **NAD⁺**; in eukaryotes uses **ATP**
