# Polymerase Chain Reaction (PCR)

**Topic Area:** Molecular Techniques
**Lecture:** [[Molecular Techniques]]
**Exam:** Final
**Importance:** MEDIUM YIELD ⭐⭐

---

## One-Line Definition
PCR is an in vitro method to exponentially amplify a specific DNA sequence using two flanking primers and a thermostable polymerase through repeated cycles of denaturation, annealing, and extension.

---

## Components
| Component | Role |
|-----------|------|
| Template DNA | Contains target |
| Forward primer | Binds bottom strand; defines left boundary |
| Reverse primer | Binds top strand; defines right boundary |
| dNTPs | Substrates for synthesis |
| **Taq polymerase** | Thermostable (from *T. aquaticus*); active at 72°C; **no 3'→5' proofreading** |
| MgCl₂ | Cofactor for Taq |

---

## Thermocycling
| Step | Temperature | Purpose |
|------|------------|---------|
| Denaturation | 94–98°C | Melt dsDNA → ssDNA |
| Annealing | 50–65°C | Primers bind templates |
| Extension | 72°C | Taq extends 5'→3' (~1 min/kb) |

**Result:** Exponential amplification (~2ⁿ copies after n cycles)

---

## Key Facts
- Taq has **no proofreading** → ~1 error per 10⁵ bp; use **Phusion/Q5** when accuracy matters
- Defined-length products (matching primer-to-primer) accumulate only from **cycle 3 onward**
- Primer Tm governs annealing temperature (usually Tm − 5°C)

---

## Applications
- Diagnostic detection (pathogen DNA, genetic variants)
- RT-PCR: reverse transcribe RNA → cDNA → PCR (detects gene expression)
- qPCR: quantify template in real time using fluorescent probes
- Site-directed mutagenesis: introduce point mutations via mismatched primers
