# DNA Topology

**Topic Area:** DNA Structure
**Lecture:** [[DNA Structure]]
**Exam:** Midterm 1
**Importance:** MEDIUM-HIGH YIELD ⭐⭐

---

## One-Line Definition
DNA topology describes the geometric properties of covalently closed circular DNA using the equation **Lk = Tw + Wr**, where the linking number (Lk) is a topological invariant that can only be changed by breaking and resealing a strand.

---

## Key Equation: Lk = Tw + Wr

| Symbol | Name | Definition |
|--------|------|-----------|
| **Lk** | Linking number | Number of times one strand crosses the other; invariant unless a strand is cut; always an **integer** |
| **Tw** | Twist | Number of helical turns of one strand about the other |
| **Wr** | Writhe | Number of times the helix axis crosses itself in 3D (supercoiling) |

**Relaxed DNA:** Wr = 0, so Lk = Tw = Lk₀ (total bp / 10.5)

**Negatively supercoiled** (as in cells): Lk < Lk₀ → Wr < 0 → underwound → favors strand separation for replication and transcription

**Positively supercoiled:** Lk > Lk₀ → Wr > 0 → overwound → forms ahead of the replication fork

---

## Topoisomerases

| Enzyme | Type | Mechanism | ΔLk per cycle | ATP? |
|--------|------|---------|--------------|------|
| Topo I | Type I | Cuts one strand, rotates, reseals | ±1 | No |
| Topo II / **Gyrase** | Type II | Cuts both strands, passes a segment, reseals | ±2 | Yes |

**DNA Gyrase** introduces **negative supercoils** — the only enzyme that can do this. Target of fluoroquinolone antibiotics (e.g., ciprofloxacin).

**Topo IV** decatenates daughter chromosomes after replication.

---

## Common Exam Traps (from NLM)
- Lk is **always an integer**
- Lk can **only change** if a phosphodiester bond is broken and reformed — stretching, bending, or partial unwinding does NOT change Lk
- **Negative supercoiling stores free energy** that aids strand separation — functionally important for transcription and replication initiation
- Topo I relaxes both positive and negative supercoils; Gyrase specifically introduces negative supercoils
