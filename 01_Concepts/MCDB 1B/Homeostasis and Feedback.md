# Homeostasis and Feedback

**Course:** [[Course Dashboard]] | **Yield:** HIGH ⭐⭐⭐

---

## Definition

Homeostasis is the maintenance of a stable internal environment despite external fluctuations. It is achieved through feedback loops that detect deviation from a set point and activate corrective responses.

## Mechanism

**Control system components:**
- **Receptor** — detects stimulus / deviation from set point
- **Control center** (integration center) — compares signal to set point; sends response
- **Effector** — carries out the response (muscle, gland)

**Negative feedback** (most common):
- Response *opposes* the stimulus and returns the variable to set point
- Examples: thermoregulation, blood glucose regulation, blood pressure

**Positive feedback** (amplifying):
- Response *reinforces* the stimulus, driving it further from set point
- Self-limiting — requires an external stop signal
- Examples: childbirth contractions, blood clotting, LH surge

## Key Components

| Parameter | Normal set point | Regulators |
|-----------|-----------------|------------|
| Core body temp | 37 °C | Hypothalamus, sweat glands, vasodilation |
| Blood glucose | ~90 mg/dL | Insulin (↓), glucagon (↑) |
| Blood pressure | ~120/80 mmHg | Baroreceptors, ADH, RAAS |
| Blood osmolarity | ~300 mOsm/L | ADH, kidneys |

## Biological Role

Homeostasis is the organizational principle of all physiology. Every organ system serves to maintain one or more homeostatic parameters. Failure of homeostatic control leads to disease (e.g., diabetes, hypertension).
