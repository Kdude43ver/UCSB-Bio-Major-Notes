# Innate vs Adaptive Immunity

**Course:** [[Course Dashboard]] | **Yield:** HIGH ⭐⭐⭐

---

## Definition

The immune system has two arms: **innate immunity** (fast, nonspecific, no memory) and **adaptive immunity** (slower, antigen-specific, generates immunological memory). Both must work together for effective defense.

## Mechanism

### Innate Immunity

**Physical and chemical barriers (first line):**
- Skin, mucus, cilia, stomach acid, lysozyme

**Cellular components (second line):**
- **Neutrophils** — first responders; phagocytosis; short-lived
- **Macrophages** — phagocytosis; present antigens; release cytokines
- **Natural killer (NK) cells** — kill virus-infected and tumor cells; recognize MHC I downregulation
- **Mast cells / basophils** — release histamine; allergic response
- **Dendritic cells** — bridge innate and adaptive; key APCs

**Complement system:** Cascade of ~30 proteins → opsonization, MAC pore formation, inflammation

**Inflammation:** Vasodilation → increased permeability → recruitment of phagocytes → redness, swelling, heat, pain. Mediated by histamine, prostaglandins, cytokines (IL-1, TNF-α).

**Pattern recognition:** Toll-like receptors (TLRs) recognize PAMPs (pathogen-associated molecular patterns).

### Adaptive Immunity

**Five properties:** Specificity, diversity, self/non-self discrimination, clonal expansion, immunological memory

**Lymphocyte development:**
- B cells: mature in bone marrow
- T cells: mature in thymus (positive + negative selection)

**Key cell types:**
| Cell | Function | MHC interaction |
|------|----------|-----------------|
| Helper T (CD4⁺) | Activate B cells and cytotoxic T cells; release cytokines | MHC II |
| Cytotoxic T (CD8⁺) | Kill infected cells via perforin/granzyme | MHC I |
| B cells / plasma cells | Produce antibodies | — |
| Memory cells | Long-lived; faster secondary response | — |

**Clonal selection:** Antigen selects and activates the lymphocyte with matching receptor → clonal expansion → effector + memory cells.
