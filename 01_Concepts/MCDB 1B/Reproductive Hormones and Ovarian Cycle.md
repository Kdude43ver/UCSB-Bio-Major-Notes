# Reproductive Hormones and Ovarian Cycle

**Course:** [[Course Dashboard]] | **Yield:** MEDIUM ⭐⭐

---

## Definition

The ovarian cycle is the 28-day hormonal sequence regulating follicle development, ovulation, and corpus luteum formation/regression. It is coordinated by a cascade involving the hypothalamus, anterior pituitary, and ovaries through feedback loops.

## Mechanism

### Hormonal Axis
```
Hypothalamus → GnRH → Anterior Pituitary → FSH / LH → Ovary → Estrogen / Progesterone
                                     ↑                              ↓ (feedback)
                               Feedback
```

### Phases of the Ovarian Cycle

**Follicular phase (days 1–13):**
- FSH stimulates follicle development → follicle produces **estrogen**
- Rising estrogen → initially inhibits FSH/LH (negative feedback)
- At peak estrogen → **positive feedback** → LH surge (day ~13)

**Ovulation (day 14):**
- LH surge → mature follicle ruptures → secondary oocyte released
- Triggered by peak estrogen → switch from negative to positive feedback

**Luteal phase (days 15–28):**
- Ruptured follicle → **corpus luteum** → secretes **progesterone** + estrogen
- Progesterone prepares uterus (thickens endometrium); inhibits FSH/LH
- If no fertilization: corpus luteum degenerates → progesterone/estrogen drop → menstruation

**If fertilization:**
- Embryo secretes **hCG** (human chorionic gonadotropin) → maintains corpus luteum → progesterone sustained → no menstruation

### Key Hormones Summary

| Hormone | Source | Role |
|---------|--------|------|
| GnRH | Hypothalamus | Pulsatile release triggers FSH/LH |
| FSH | Anterior pituitary | Follicle development |
| LH | Anterior pituitary | Ovulation (surge); corpus luteum |
| Estrogen | Follicle / corpus luteum | Endometrial growth; LH surge feedback |
| Progesterone | Corpus luteum | Endometrial maintenance; inhibits FSH/LH |
| hCG | Embryo | Maintains corpus luteum in early pregnancy |

### Uterine Cycle
- **Menstruation** (days 1–5): endometrium shed
- **Proliferative phase** (days 6–14): estrogen stimulates endometrial regrowth
- **Secretory phase** (days 15–28): progesterone stimulates gland secretion, nutrient-rich endometrium
