# Cardiac Cycle and ECG

## Definition

The cardiac cycle is the sequence of electrical and mechanical events comprising one heartbeat (systole + diastole). The electrocardiogram (ECG/EKG) records the electrical activity of the heart and reflects the wave of depolarization/repolarization through cardiac muscle.

## Mechanism

**Cardiac conduction pathway:**
```
SA node → AV node (0.1 s delay) → Bundle of His → Bundle branches → Purkinje fibers
```

- **SA node** (right atrium): pacemaker, ~70 bpm intrinsic rate
- **AV node** delay: allows atria to finish contracting before ventricles fire
- **Purkinje fibers**: rapid conduction → apex-to-base contraction for efficient ejection

**ECG waveforms:**

| Wave | Event |
|------|-------|
| **P wave** | Atrial depolarization |
| **QRS complex** | Ventricular depolarization (atrial repolarization hidden) |
| **T wave** | Ventricular repolarization |
| **PR interval** | AV node delay |
| **QT interval** | Ventricular action potential duration |

**Mechanical cycle (one beat):**
1. **Atrial systole** → fills ventricles
2. **Isovolumetric contraction** → pressure builds, valves closed
3. **Ventricular ejection** → semilunar valves open
4. **Isovolumetric relaxation** → all valves closed
5. **Passive ventricular filling** → AV valves open

**Frank-Starling Law:** Greater ventricular stretch (end-diastolic volume) → stronger contraction → more stroke volume (within physiological range).

## Key Values

| Parameter | Normal value |
|-----------|-------------|
| Heart rate | 60–100 bpm |
| Stroke volume | ~70 mL |
| Cardiac output | HR × SV ≈ 5 L/min |
| Systolic BP | ~120 mmHg |
| Diastolic BP | ~80 mmHg |
