## Definition

Antibodies (immunoglobulins) are Y-shaped glycoproteins produced by plasma cells (differentiated B cells) that bind specific antigens. They mediate humoral immunity through neutralization, opsonization, and complement activation.

## Mechanism

**Structural domains:**
```
        [VH]  [VL]   ← Variable regions (antigen-binding)
         |      |
[CH1]──[CL]           ← Fab arms (2 per antibody)
  |
[CH2]
  |                   ← Fc region (effector functions)
[CH3]
```

- **Heavy chains** (2): CH1–CH3 constant domains; VH variable domain
- **Light chains** (2): CL constant; VL variable
- **Fab fragment**: antigen-binding portion (VH + VL); 2 per antibody
- **Fc fragment**: binds Fc receptors on phagocytes; activates complement
- **Hinge region**: flexible; allows Fab arms to move

**Isotypes and functions:**

| Class | Location | Function |
|-------|----------|----------|
| **IgG** | Blood, tissues | Main secondary response; opsonization; crosses placenta |
| **IgM** | Blood (pentamer) | Primary response; complement activation |
| **IgA** | Mucosal secretions (dimer) | Neutralization at mucosae |
| **IgE** | Bound to mast cells | Allergy; parasite defense |
| **IgD** | B cell surface | BCR co-receptor; signaling |

**Mechanisms of antigen elimination:**
1. **Neutralization** — blocks viral/toxin entry
2. **Opsonization** — tags pathogens for phagocytosis (Fc receptor recognition)
3. **Complement activation** → MAC formation, inflammation
4. **ADCC** (antibody-dependent cellular cytotoxicity) — NK cells kill Ab-coated cells
