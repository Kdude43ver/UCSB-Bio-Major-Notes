## 🌲 Full Course Tree

```
MCDB 1B: Animal and Plant Physiology
│
├── PART I: ANIMAL PHYSIOLOGY
│   │
│   ├── 01. Introduction & Homeostasis
│   │   ├── Tissue types: epithelial, connective, muscle, nervous
│   │   ├── Homeostasis: stable internal environment via feedback
│   │   ├── Negative feedback — opposes stimulus, returns to set point
│   │   │   └── Examples: thermoregulation, blood glucose, BP, osmolarity
│   │   ├── Positive feedback — amplifies stimulus; requires external stop
│   │   │   └── Examples: LH surge, childbirth, blood clotting
│   │   └── Control system: receptor → control center → effector
│   │
│   ├── 02. Nervous System
│   │   ├── Neuron anatomy: soma, dendrites, axon, myelin sheath, terminals
│   │   ├── Glial cells: oligodendrocytes (CNS), Schwann cells (PNS)
│   │   ├── CNS (brain + spinal cord) vs PNS (somatic + autonomic)
│   │   ├── Resting membrane potential (-70 mV)
│   │   │   ├── K+ leakage outward; Na+ excluded; intracellular anions
│   │   │   └── Na+/K+ ATPase: 3 Na+ out / 2 K+ in (electrogenic)
│   │   ├── Action potential
│   │   │   ├── Threshold ~-55 mV
│   │   │   ├── Depolarization: voltage-gated Na+ channels open
│   │   │   ├── Repolarization: Na+ inactivate; K+ channels open
│   │   │   ├── Hyperpolarization: K+ channels slow to close
│   │   │   └── Refractory period: absolute + relative
│   │   ├── Propagation: saltatory (myelinated) vs continuous
│   │   └── Synaptic transmission
│   │       ├── Ca2+ influx → vesicle fusion (SNARE) → NT release
│   │       ├── Ionotropic vs metabotropic receptors
│   │       ├── EPSP (Na+/Ca2+ in) and IPSP (Cl- in / K+ out)
│   │       └── Temporal + spatial summation at axon hillock
│   │
│   ├── 03. Sensory Systems
│   │   ├── Sensory processing: reception → transduction → transmission → perception
│   │   ├── Receptor types: mechanoreceptor, chemoreceptor, thermoreceptor, photoreceptor
│   │   ├── Sensory adaptation at constant stimulus
│   │   └── Vision
│   │       ├── Eye anatomy: cornea → lens → vitreous → retina → fovea
│   │       ├── Rods (dim light, periphery) vs Cones (color, fovea)
│   │       └── Phototransduction: rhodopsin → transducin → PDE → cGMP drops
│   │           ├── Dark: cGMP high → channels open → depolarized → Glu release
│   │           └── Light: cGMP low → channels close → hyperpolarized → Glu stops
│   │
│   ├── 04. Muscular System
│   │   ├── Three types: skeletal (voluntary), smooth (involuntary), cardiac
│   │   ├── Sarcomere structure
│   │   │   ├── Z-disc (borders), A-band (myosin), I-band (actin only), H-zone (myosin only)
│   │   │   ├── A-band DOES NOT shorten during contraction
│   │   │   └── I-band and H-zone shorten; Z-disc distance decreases
│   │   ├── Sliding filament model
│   │   ├── Cross-bridge cycle (4 steps, each ATP role)
│   │   │   ├── ATP binds → myosin detaches
│   │   │   ├── ATP hydrolysis → myosin cocked (90 degrees)
│   │   │   ├── Pi release → power stroke (90 to 45 degrees)
│   │   │   └── ADP release → rigor state
│   │   ├── Ca2+ regulation: troponin C → tropomyosin shifts → actin exposed
│   │   └── Excitation-contraction coupling: AP → T-tubule → RYR → Ca2+ from SR
│   │
│   ├── 05. Circulatory System
│   │   ├── Open vs closed circulatory systems
│   │   ├── Heart: 4 chambers, 4 valves; pulmonary + systemic circuits
│   │   ├── Cardiac conduction
│   │   │   ├── SA node → AV node (0.1 s delay) → Bundle of His → Purkinje
│   │   │   └── ECG: P wave (atrial depol.), QRS (ventricular depol.), T wave (repol.)
│   │   ├── Cardiac output = HR x Stroke Volume (~5 L/min rest)
│   │   ├── Frank-Starling: greater stretch → greater contraction
│   │   ├── BP (120/80 mmHg): baroreceptor reflex (short) + RAAS/ADH (long)
│   │   └── Capillary exchange: filtration (arteriole end), reabsorption (venule end)
│   │
│   ├── 06. Respiratory System
│   │   ├── Gas exchange by passive diffusion down partial pressure gradients
│   │   ├── Counter-current exchange in fish gills (max O2 extraction)
│   │   ├── Lung alveoli: thin membranes; surfactant prevents collapse
│   │   ├── Hemoglobin and O2 transport
│   │   │   ├── Tetrameric; sigmoidal curve; cooperative binding
│   │   │   ├── Bohr effect: CO2 up, pH down, temp up, 2,3-BPG up → right shift → more O2 off
│   │   │   └── CO2 transport: dissolved (7%), bicarbonate (70%), carbaminoHb (23%)
│   │   └── Bicarbonate buffer: CO2 + H2O <-> H+ + HCO3-
│   │
│   ├── 07. Digestive System
│   │   ├── GI tract: mouth → esophagus → stomach → small intestine → large intestine
│   │   ├── Accessory: liver (bile), gallbladder, pancreas (enzymes + HCO3-)
│   │   ├── Enzymes: amylase (starch), pepsin (protein, pH 2), lipase (fats), trypsin
│   │   ├── Bile emulsifies fats (not enzyme); chylomicrons → lacteals → lymph
│   │   ├── Carbs/proteins → capillaries → portal vein → liver
│   │   ├── Adaptations: villi + microvilli (brush border)
│   │   └── Hormones: gastrin, secretin, CCK, leptin
│   │
│   ├── 08. Endocrine & Reproductive Systems
│   │   ├── Signaling modes: endocrine, paracrine, autocrine
│   │   ├── Steroid hormones: lipid-soluble, intracellular receptor, slow
│   │   ├── Peptide hormones: water-soluble, surface GPCR, fast, second messengers
│   │   ├── Key hormones: insulin, glucagon, cortisol, aldosterone, ADH, estrogen, LH, FSH
│   │   ├── HPG axis: hypothalamus (GnRH) → anterior pituitary (LH/FSH) → gonads
│   │   └── Ovarian cycle
│   │       ├── Follicular (days 1-13): FSH → estrogen rises → negative → positive feedback
│   │       ├── Ovulation (day 14): LH surge → follicle ruptures
│   │       └── Luteal (days 15-28): corpus luteum → progesterone → regresses → cycle restarts
│   │
│   ├── 09. Excretory System
│   │   ├── Waste forms: ammonia (aquatic), urea (terrestrial mammals), uric acid (birds/reptiles)
│   │   ├── Nephron: Bowman's → PCT → Loop of Henle → DCT → Collecting Duct
│   │   ├── Four steps: filtration → reabsorption → secretion → excretion
│   │   ├── PCT: all glucose + AA, ~65% Na+/water (obligatory)
│   │   ├── Loop of Henle: countercurrent multiplier → 300 to 1200 mOsm gradient
│   │   │   ├── Descending: water permeable → filtrate concentrated
│   │   │   └── Ascending thick: NaCl pumped out; water impermeable → diluted
│   │   ├── DCT: fine-tuning Na+ (aldosterone) and Ca2+ (PTH)
│   │   └── Collecting duct: ADH → AQP-2 → concentrated urine OR dilute urine (no ADH)
│   │
│   └── 10. Immune System
│       ├── Innate: barriers, neutrophils, macrophages, NK cells, complement, TLRs/PAMPs
│       ├── Inflammation: vasodilation, leakiness, phagocyte recruitment
│       ├── Adaptive: clonal selection, memory, 5 properties
│       ├── B cells → plasma cells → antibodies (humoral)
│       │   └── IgM (primary), IgG (secondary, crosses placenta), IgA (mucosae), IgE (allergy)
│       ├── CD4+ T helper: recognizes MHC II; activates B cells + CD8+ cells
│       ├── CD8+ cytotoxic T: recognizes MHC I; perforin + granzyme → apoptosis
│       ├── MHC I: all nucleated cells; intracellular peptides
│       └── MHC II: APCs only (dendritic, macrophage, B cell); extracellular peptides
│
└── PART II: PLANT PHYSIOLOGY
    │
    ├── 11. Plant Structure & Growth
    │   ├── Unique structures: cell wall, central vacuole (turgor), chloroplasts, plasmodesmata
    │   ├── Cell wall: primary (cellulose + pectin, flexible) vs secondary (lignified, rigid)
    │   ├── Tissue types: dermal (epidermis, stomata), ground (parenchyma, sclerenchyma), vascular
    │   ├── Primary growth: apical meristems → length
    │   └── Secondary growth: vascular cambium + cork cambium → girth
    │
    ├── 12. Transport in Plants
    │   ├── Water potential: Psi = Psi_s + Psi_p; water moves to more negative Psi
    │   ├── Pathways: apoplastic (cell walls) vs symplastic (plasmodesmata)
    │   ├── Casparian strip: waxy endodermal barrier; forces water into symplast
    │   ├── Xylem (water up): TACT — Transpiration, Adhesion, Cohesion, Tension
    │   │   └── Dead cells (tracheids + vessels); lignified walls
    │   ├── Stomata
    │   │   ├── Opening: blue light → H+ ATPase → K+ in → osmosis → guard cells swell
    │   │   └── Closing: ABA → K+ out → water loss → shrink
    │   └── Phloem (sugars, bidirectional): source-to-sink pressure flow model
    │       ├── Source: active sucrose loading → water in → pressure
    │       └── Sink: sucrose unloaded → water out → pressure decreases
    │
    ├── 13-14. Photosynthesis
    │   ├── Light Reactions (thylakoid membranes)
    │   │   ├── Z-scheme: H2O → PSII (P680) → PQ → Cyt b6f → PC → PSI (P700) → Fd → NADPH
    │   │   ├── OEC splits H2O → O2 + H+ + electrons
    │   │   ├── H+ gradient (lumen) → ATP synthase → ATP
    │   │   └── Cyclic photophosphorylation: PSI loop → ATP only
    │   ├── Calvin Cycle (stroma)
    │   │   ├── Stage 1: CO2 fixation — RuBisCo + RuBP + CO2 → 2x 3-PGA
    │   │   ├── Stage 2: Reduction — 3-PGA + NADPH + ATP → G3P
    │   │   └── Stage 3: Regeneration — G3P → RuBP (uses ATP)
    │   ├── Photorespiration: RuBisCo + O2 → wasteful; worsened by heat/drought
    │   └── C4 vs CAM adaptations
    │       ├── C4 (corn, sugarcane): PEPcase in mesophyll; CO2 concentrated in bundle sheath (SPATIAL)
    │       └── CAM (cactus, agave): CO2 at night via PEPcase; Calvin cycle runs by day (TEMPORAL)
    │
    └── 15. Plant Responses
        ├── Auxin (IAA): cell elongation, phototropism, gravitropism, apical dominance
        ├── Gibberellins: stem elongation, seed germination (alpha-amylase induction)
        ├── Cytokinins: cell division; oppose auxin in lateral bud suppression
        ├── Ethylene (gas): fruit ripening, abscission, triple response; autocatalytic
        ├── ABA: stomatal closure, seed dormancy, stress response
        └── Phytochrome
            ├── Pr (inactive) + red light (660 nm) → Pfr (active)
            ├── Pfr + far-red (730 nm) OR darkness → Pr
            └── Controls: photoperiodism, seed germination, shade avoidance
```
