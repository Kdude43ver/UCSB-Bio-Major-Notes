## 🧠 Core Concepts

### Innate vs. Adaptive Immunity

| Feature | **Innate Immunity** | **Adaptive Immunity** |
|---|---|---|
| **Speed** | Immediate (minutes–hours) | Slow (days–weeks first exposure) |
| **Specificity** | Broad — recognizes general pathogen patterns (PAMPs) | Highly specific — recognizes individual antigens |
| **Memory** | No | Yes — faster/stronger on re-exposure |
| **Components** | Physical barriers, macrophages, NK cells, complement, inflammation | B cells, T cells, antibodies |
| **Diversity** | Limited | Enormous (recombination of receptor genes) |

**Key innate components:**
- **Physical barriers:** Skin, mucus, cilia
- **Macrophages:** Phagocytosis; present antigens to T cells
- **Neutrophils:** First responders; phagocytosis
- **NK cells:** Kill virus-infected and cancer cells
- **Complement system:** Protein cascade; lyses pathogens
- **Inflammation:** Redness, swelling, heat — recruits immune cells

### Five Features of Adaptive Immunity

1. **Specificity:** Each B/T cell recognizes ONE specific antigen (epitope)
2. **Diversity:** Enormous range of antigen receptors via V(D)J recombination
3. **Clonal expansion:** Antigen-activated cells rapidly divide
4. **Self/non-self discrimination:** Tolerance mechanisms eliminate self-reactive cells
5. **Memory:** Long-lived memory cells respond faster/stronger on re-exposure

> ⚠️ **Exam Trap (from past exam):** "What is NOT a feature of the immune system?"
> Answer choice: "Specificity: The capacity of a SINGLE antibody to bind to MULTIPLE different PAMPs" — this is FALSE. Each antibody is specific to ONE epitope.

### MHC Molecules (Major Histocompatibility Complex)

| Feature | **MHC Class I** | **MHC Class II** |
|---|---|---|
| **Expressed on** | ALL nucleated cells | Only antigen-presenting cells (APCs): macrophages, dendritic cells, B cells |
| **Presents** | Intracellular antigens (virus proteins, cancer) | Extracellular antigens (bacteria phagocytosed) |
| **Activates** | Cytotoxic T cells (CD8⁺) | Helper T cells (CD4⁺) |
| **Role in transplants** | Foreign MHC I triggers rejection | — |

> ⚠️ **Transplant rejection:** The recipient's cytotoxic T cells recognize foreign MHC I on the donor organ cells as "non-self" → attack and destroy the organ.

### Humoral (Antibody-Mediated) Immune Response

1. Antigen enters → presented by APC via MHC II
2. **Helper T cell (CD4⁺)** recognizes antigen–MHC II complex → activated
3. Helper T cell activates **B cells**
4. B cells proliferate (**clonal expansion**) → differentiate into **plasma cells**
5. **Plasma cells** secrete **antibodies** specific to the antigen
6. **Memory B cells** form for faster future responses

### Antibody Structure

- **Y-shaped** glycoprotein
- 2 **heavy chains** + 2 **light chains** connected by **disulfide bridges**
- **Variable region (Fab):** Antigen-binding site — unique to each antibody
- **Constant region (Fc):** Effector functions (complement activation, opsonization)
- **Epitope:** The specific part of the antigen that the antibody binds

### Cellular Immune Response (vs. intracellular pathogens/cancer)

1. Infected cell presents viral peptides on **MHC Class I**
2. **Cytotoxic T cell (CD8⁺)** recognizes MHC I–antigen complex via T cell receptor (TCR)
3. Cytotoxic T cell undergoes **clonal expansion** (activation phase)
4. **Effector phase:** Cytotoxic T cells release **perforin** → punches holes in infected cell membrane → **lysis**
