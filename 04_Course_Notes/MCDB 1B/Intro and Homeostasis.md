## 🧠 Core Concepts

### What is an Animal?
Animals are multicellular, heterotrophic organisms composed of >30 trillion cells (in humans). Cells are organized into tissues → organs → organ systems. Cells are highly specialized; very few are non-specialized.

### Four Tissue Types

| Tissue | Function | Example |
|---|---|---|
| **Epithelial** | Covers/lines organs, protection, secretion, absorption | Skin, gut lining, photoreceptors |
| **Connective** | Supports and binds tissues, provides structure | Bone, cartilage, blood, adipose |
| **Muscle** | Contracts to generate force and movement | Skeletal, smooth, cardiac |
| **Nervous** | Processes and transmits electrical signals | Neurons, glial cells |

> ⚠️ **Exam Trap:** Connective tissue does NOT line organs — that is epithelial tissue. A common wrong answer swaps these two.

### Homeostasis

**Definition:** The maintenance of a stable internal environment despite a constantly changing external environment.

**Key Parameters:**

| Parameter | Regulated By |
|---|---|
| Oxygen | Respiratory + Circulatory |
| Temperature | Circulatory + Skin (sweating) + Muscles (shivering) |
| pH | Respiratory + Excretory |
| Osmolarity | Digestive + Excretory + Circulatory |
| Glucose/nutrients | Digestive + Adipose/Liver + Circulatory |
| Ion composition | Digestive + Excretory + Circulatory |
| Nitrogenous waste | Excretory + Respiratory |

### Feedback Loops

#### Negative Feedback (most common in homeostasis)
- Detects deviation from set point → triggers response to **reverse** the change
- Maintains stability
- **Example:** Body overheating → sweating → body cools down
- **Exam question:** "You start sweating during your 1B exam because the room is hot. This is a ______ and ______."
  - **Answer: Negative feedback loop; homeostasis**

#### Positive Feedback (amplifies change)
- Detects deviation → triggers response that **amplifies** the change
- NOT homeostasis; moves away from set point
- **Example:** Uterine contractions during labor (oxytocin release → more contractions → more oxytocin)
- **Example:** Blood clotting cascade

> ⚠️ **Common Misconception:** Positive feedback is NOT always bad — it serves important biological functions, but it is NOT a mechanism for maintaining homeostasis.

### Control Mechanisms for Homeostasis

Three components are required:
1. **Receptor/Sensor** — monitors status of a parameter
2. **Control center** — analyzes the signal (often the brain)
3. **Effector** — carries out the corrective response
