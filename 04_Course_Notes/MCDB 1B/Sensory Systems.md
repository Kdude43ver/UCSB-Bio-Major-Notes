## 🧠 Core Concepts

### Four Steps of Sensory Processing (universal)

1. **Sensory reception** — capture the energy of the sensory stimulus
2. **Transduction** — convert the stimulus into the language of the nervous system (change in membrane potential)
3. **Transmission** — send the signal to the brain
4. **Perception** — conscious awareness of the input

> Most sensory cells are **modified neurons** specialized for specific stimuli.

### Types of Sensory Receptors

| Type | Detects | Example |
|---|---|---|
| **Mechanoreceptor** | Mechanical stimuli (pressure, vibration, stretch) | Hair cells in cochlea (hearing), skin pressure receptors |
| **Chemoreceptor** | Chemical stimuli (taste, smell, blood O₂/CO₂) | Olfactory neurons, taste buds, carotid body |
| **Photoreceptor** | Light | Rods and cones in the retina |
| **Thermoreceptor** | Temperature | Skin |
| **Ionotropic** | Directly converts stimulus to membrane potential change | Many photoreceptors |

### The Human Eye

**Anatomy (light travels through in this order):**

```
Light → Cornea → Pupil (iris controls diameter) → Lens → Vitreous humor → Retina
```

| Structure | Function |
|---|---|
| **Cornea** | Transparent outer layer; does most of the focusing |
| **Iris** | Pigmented ring; controls pupil size (light entry) |
| **Pupil** | Opening that lets light in |
| **Lens** | Adjustable focusing (accommodation) |
| **Aqueous humor** | Fluid between cornea and lens; maintains pressure |
| **Vitreous humor** | Gel-like fluid in the main eye chamber |
| **Retina** | Contains photoreceptors (rods and cones) |
| **Fovea** | Central pit; highest cone density; sharpest vision |
| **Optic disk** | Where optic nerve exits; no photoreceptors = "blind spot" |
| **Sclera** | White outer layer; structural support |
| **Choroid** | Vascular layer; supplies nutrients |

> ⚠️ Light must pass through **several layers of neurons** before reaching the photoreceptors — the retina is "inverted."

### Rods vs. Cones

| Feature | Rods | Cones |
|---|---|---|
| **Distribution** | Peripheral retina | Fovea (center) |
| **Sensitivity** | High — work in dim light | Low — need bright light |
| **Color vision** | No (black and white) | Yes (3 types: R, G, B) |
| **Acuity** | Low | High |
| **Pigment** | Rhodopsin | Color opsins |

**Phototransduction (in rods):**
1. Light hits **rhodopsin** (retinal + opsin)
2. Retinal changes shape (11-cis → all-trans)
3. Activates G-protein (transducin)
4. Closes cGMP-gated Na⁺ channels → membrane hyperpolarizes
5. Reduced neurotransmitter release → signal to bipolar cells → ganglion cells → optic nerve → brain
